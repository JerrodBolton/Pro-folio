## Click behavior

- Take the visitor directly to the official Animai Kingdom website in the current tab.
- Replace existing SIP or Animai Kingdom internal destinations with the official external URL.
- A click on an Animai Kingdom or SIP project card should go directly to the official website instead of opening an internal detail page, modal, or flip interaction. Other objective card interactions may remain, but their Animai Kingdom entry must link directly to the external website.
- Link relevant words within paragraphs without making unrelated surrounding content clickable.
- Use semantic, keyboard-accessible anchor links with visible focus states and meaningful accessible names. Avoid nested links or buttons inside a linked card.
- Keep the destination in one shared configuration value so changing the domain updates every reference.

Keep brief portfolio summaries and degree objective explanations as needed. Direct visitors to the separate Animai Kingdom website for full project information, development details, and updates. Do not build a second full SIP website inside the personal portfolio.
