Project

VORTEXA

In development

Desktop local-LLM assistant with a chat interface, model switching and session conversation history.

1. Purpose

What it does and which problem it solves.

Desktop local-LLM assistant with a chat interface, model switching and session conversation history.

2. Status

Working features and planned features, clearly separated.

In the source code now: a modular GUI, worker threads and queues, model loading and streamed responses. It prefers the Dolphin3.0-Llama3.1-8B GGUF model and falls back to other GGUF files it finds. It also has a system persona, recent message history and token-budget trimming.

Still to do: confirm the installed model, hardware and dependencies, run it end to end, and save before/after tests of its language behavior.
